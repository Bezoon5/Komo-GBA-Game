# Contributing

Thanks for your interest in Kōmō.

## Reporting a problem

Open an issue with:
- where you played (the web player, an emulator and its version, or hardware such as the Analogue Pocket and its core);
- the floor, difficulty and what happened;
- a screenshot or a short video if it's a graphics problem.

## Changing the game

1. Build it first (see [docs/BUILDING.md](docs/BUILDING.md)).
2. Make your change. Most of the game is in `src/main.c`; the fighters, stages and music are generated by the scripts in `tools/`.
3. Check it with the desktop harness: the sanitizer build (`out/host_test`) should run clean, for example
   `./out/host_test 20000 0 0 1 1` and `./out/host_test 20000 0 11 1 1` (the scripted control test).
4. If you changed `tools/fighters.py`, mirror the change in `tools/designer/render.js` so the designer still matches the game, and rebuild the designer.
5. Open a pull request describing what changed and how you tested it.

## Character designs

Designs made in the [character designer](play/designer.html) can be exported as `characters.json` and attached to an issue.
